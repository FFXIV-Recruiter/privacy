# privacy

Privacy policy for Alpha, the FFXIV Recruiter community Discord bot.

Published at **<https://ffxiv-recruiter.github.io/privacy/>** — that URL is the
canonical version, and the one registered with Discord. This repository is the
source it is built from.

The policy describes real behaviour, not intent: every claim in it was checked
against the bot's code before publication. If the bot's data handling changes,
this file changes with it.
